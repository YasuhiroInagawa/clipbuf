# プラットフォーム確認チェックリスト

自動テストで押さえられない項目を、リリース前に実機で確認するための一覧。CI（3 OS の lint / 型 /
テスト / ビルド）が緑であることを前提に、その上で人間が見るべきものだけを挙げる。

各項目は「操作 → 期待」の形で書いてある。期待どおりでなければ、要件番号を添えて issue にする。

## 全 OS 共通

### 取り込み

- [ ] ブラウザ・エディタ・ターミナルのそれぞれでコピー → **1 秒以内**に一覧の先頭に出る（1.1, 1.2）
- [ ] ブラウザで**書式付き**の範囲をコピー → 「書式あり」の警告アイコンが付く（1.4）
- [ ] 同じテキストを続けて 2 回コピー → 一覧に 1 件しか増えない（重複排除）
- [ ] 保持件数（既定 20）を超えてコピー → 最古の項目が消え、件数が増え続けない（2.2）
- [ ] パスワードマネージャでパスワードをコピー → **一覧に出ない**（1.8）。macOS ならパスワード
      マネージャがなくても確認できる: `swift scripts/macos-concealed-copy.swift "secret"`
- [ ] clipbuf 自身で転送 → その内容が一覧に**新規追加されない**（1.5）

### 表示

- [ ] 改行を含むテキスト → 一覧は 1 行表示（改行は記号）、全文プレビューでは改行位置が見える（3.1）
- [ ] 半角空白・全角空白・タブ・NBSP・ゼロ幅スペースを含むテキスト → それぞれ別の記号と色で出る
- [ ] CRLF / LF / CR を混在させたテキスト → 色が 3 種類に分かれ、凡例がプレビュー下部に出る（3.7–3.9）
- [ ] 記号にポインタを合わせる → 何の文字かツールチップで分かる
- [ ] 警告アイコンにポインタを合わせる → 何が問題かツールチップで分かる

### 転送

- [ ] 行をクリック → 緑のハイライト → 他アプリに貼り付けると期待どおりの内容（6.1）
- [ ] 「プレーン」ボタン → 転送オプションを適用した結果が貼り付けられる
- [ ] 「原文」ボタン（書式ありの項目のみ）→ 設定に関わらず無変換の内容が貼り付けられる（6.4.1）
- [ ] 転送後も一覧の順序と選択位置が変わらない（6.5）
- [ ] 各トグル（書式保持 / 改行 / トリム / タブ→空白 / 全角空白→半角）の組み合わせで、
      プレビューの表示と実際に貼り付けられる内容が**一致する**（4.7）
- [ ] 「書式を保持」をオンにして転送 → テキスト変換が適用されず、その旨の通知が出る（6.9）

### ウィンドウ・ホットキー

- [ ] グローバルホットキー（既定 `Alt+Shift+V`）で表示・非表示が切り替わる（8.2）
- [ ] 非表示から表示 → 最新の項目が選択されている（8.3）
- [ ] ↑↓ で選択移動、Enter で転送、Shift+Enter でプレーン転送、Delete で削除、Esc で非表示
- [ ] ウィンドウを閉じる操作 → アプリは終了せず非表示になる（8.5）
- [ ] 位置とサイズを変えて再起動 → 維持されている（8.6）
- [ ] 他アプリを前面にしても clipbuf が最前面に残る（8.1）
- [ ] トレイ / メニューバーから 表示切替・設定・About・終了 ができる（8.4, 8.8）

### 設定

- [ ] 保持件数を減らして保存 → 一覧がその場で切り詰められ、**その後のコピーでも増えない**（9.2）
- [ ] ホットキーを記録 → 記録中は現在のホットキーが効かない。保存後は新しいキーで動く（9.5.1）
- [ ] 他アプリが使っているホットキーを指定 → ホットキー欄にエラーが出て、入力が保持される（9.4）
- [ ] 保存 → 設定ウィンドウが閉じる。保存せず閉じる → 編集内容が破棄される（9.7, 9.8）
- [ ] UI 言語を切り替え → **再起動なしで**両ウィンドウに反映される（12.4）
- [ ] 「ログイン時に起動」をオンにして再ログイン → 自動で起動し、ウィンドウは非表示のまま

### About・更新

- [ ] トレイメニューの About → バージョン・作者・ライセンス・リポジトリが出る（8.8）
- [ ] リポジトリのリンク → **既定のブラウザ**で開く（clipbuf のウィンドウが遷移しない）（8.9）
- [ ] 配布物の中に `LICENSE` と `THIRD-PARTY.md` が入っている（13.9）
- [ ] 新しいバージョンがある状態で起動 → バナーが出る。「あとで」で消え、現在のバージョンで継続（13.8）
- [ ] 「更新する」→ ダウンロード → 再起動を促され、再起動後に新しいバージョンになっている（13.7）

## Windows

- [ ] インストーラ実行 → SmartScreen の警告が出る。README の手順（詳細情報 → 実行）で起動できる（13.4）
- [ ] インストール先が**管理者権限なし**で書き込める場所になっている（NSIS のユーザーインストール）
- [ ] 設定画面に「ポーリング間隔」が**出ない**（Windows はイベント駆動）
- [ ] タスクバーに clipbuf のボタンが出ない（常駐アプリとして邪魔をしない）
- [ ] コマンドプロンプトからのコピー（CRLF）が正しく色分けされる
- [ ] アンインストール後、設定ファイルの残骸を確認する

## macOS

- [ ] dmg から起動 → **Gatekeeper の警告が出ない**（署名・公証済み。未署名ビルドでは出る）（13.3）
- [ ] Apple Silicon と Intel の両方で起動する（universal バイナリ）
- [ ] Dock にアイコンが出ず、メニューバーにだけ常駐する（8.4）
- [ ] クリップボード読み取りが拒否される環境 → 「システム設定 › プライバシーとセキュリティ ›
      ペーストボード」を案内するメッセージが出る（11.6）
- [ ] 設定画面に「ポーリング間隔」が**出る**（macOS はポーリング）
- [ ] 複数のデスクトップ（Space）を切り替えても、ウィンドウが付いてくる

## Linux — X11

- [ ] 全アプリからのコピーが取り込める（11.3）
- [ ] 設定画面に「ポーリング間隔」が**出ない**（X11 はイベント駆動）
- [ ] トレイアイコンが出る（AppIndicator のない環境では出ないことがある。その場合はホットキーで操作）
- [ ] AppImage / deb / rpm のそれぞれで起動する

## Linux — KDE Plasma (Wayland)

- [ ] 全アプリからのコピーが取り込める（`wlr-data-control` 経由）（11.4）
- [ ] 設定画面に「ポーリング間隔」が**出る**
- [ ] パスワードマネージャの `x-kde-passwordManagerHint` が付いた内容を取り込まない（1.8）

## Linux — GNOME (Wayland)

- [ ] 「Wayland で data-control が使えないため、X11/XWayland アプリからのコピーのみ取り込みます」が
      ウィンドウ上部に表示される（11.5）
- [ ] XWayland で動くアプリからのコピーは取り込める
- [ ] ネイティブ Wayland アプリからのコピーは取り込まれない（バナーの説明と実際の挙動が一致する）
- [ ] グローバルホットキーが効かない場合、トレイまたはコマンドラインから起動して操作できる

## リリース前

- [ ] `src-tauri/tauri.conf.json` の `version` を上げてからタグを打つ。`latest.json` の `version` は
      **タグではなくこの設定ファイル**から来るので、上げ忘れると誰にも更新が届かない
- [ ] `README.md` と `README.ja.md` の内容が揃っている（片方だけ更新して放置していない）
- [ ] CI の 3 ジョブが緑（6.1）
- [ ] ドラフトリリースに 3 OS の配布物、`latest.json`、`SHA256SUMS.txt`、`THIRD-PARTY.md` が揃っている
- [ ] `SHA256SUMS.txt` の値が、実際にダウンロードしたファイルのハッシュと一致する（13.5）
- [ ] 旧バージョンから新バージョンへの更新が、3 OS のうち少なくとも 1 つで実際に通る（13.7）
