# Product Overview

clipbuf は、デスクトップ（Windows / macOS / Linux）でアプリ間のコピー＆ペーストを行う人のための
クリップボードバッファアプリ。他アプリでコピーされたテキストを自動で取り込み、直近 N 件を
1 行ずつリスト表示し、**貼り付ける前に事故要因を見せ、1 クリックで無害化してクリップボードへ戻す**。

無料・オープンソース（MIT）。個人プロジェクトとして GitHub Releases で配布し、販売しない。

## Core Capabilities

- **自動取り込み**: 他アプリでのコピー（テキストのみ）を OS のクリップボード変化として観測し、FIFO で直近 N 件を保持する
- **可視化**: 半角/全角空白、タブ、改行、NBSP・ゼロ幅スペース等を記号と色で区別して 1 行プレビューに表示する
- **警告**: スタイル（HTML/RTF）の有無、先頭末尾の空白・改行、タブ、機種依存文字、制御文字、改行コード混在などをアイコン列で示す
- **無害化転送**: スタイル削除、改行の削除/空白置換、トリム、タブ変換、全角空白変換をトグルで選び、行クリック 1 回でクリップボードへ書き戻す
- **常駐**: 常に最前面の小さなフローティングウィンドウ。グローバルホットキーで表示切替、トレイ/メニューバーに常駐

## Target Use Cases

- Web ページや PDF からコピーした文章を、書式を持ち込まずにエディタやチャットへ貼る
- 表計算やターミナルからコピーしたテキストの、末尾の改行・タブ混入を貼る前に取り除く
- コード片やパスのコピーで、見えない全角空白・NBSP が混ざっていないか確認する
- 直近にコピーした複数の断片を、順に貼り付け先へ流し込む

## Value Proposition

既存のクリップボード履歴ツール（CopyQ, Clipy, Maccy, Ditto 等）は「履歴の保持と再貼り付け」が主目的で、
貼り付け事故の原因を事前に見せる機能を持たない。clipbuf の差別化は次の 3 点：

1. **見える**: 不可視文字と書式の有無をプレビューと警告で可視化する
2. **止められる**: 貼る前に事故要因に気づける
3. **直せる**: 転送時のトグルで無害化し、元データは壊さない（非破壊）

## Product Principles

- **端末内で完結**: 取り込んだ内容をディスクに保存せず、ネットワークにも送らない（更新確認のみ例外）
- **非破壊**: 転送オプションは書き込む内容にだけ作用し、リスト上の元データは変えない
- **邪魔をしない**: コピー元・貼り付け先アプリの挙動には介入しない。観測するだけ
- **秘匿の尊重**: パスワードマネージャ等の「監視対象外」マークが付いた内容は取り込まない
- **スコープを広げない**: 画像・ファイル履歴、永続化、検索、クラウド同期、画面端ドッキングは初期リリースでは扱わない
